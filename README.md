# IT-Service-Desk-Implementation
Design and implementation of an IT Service Desk using Jira Service Management, including workflows, SLAs, automation and ITSM processes.

## 📚 Documentación técnica

La implementación se encuentra documentada en los siguientes apartados:

| Documento | Descripción |
|-----------|-------------|
| [Diseño de workflows](docs/workflows.md) | Estados, transiciones, escalamiento y ciclo de vida de los tickets. |
| [Gestión de SLA](docs/sla.md) | Tiempos de respuesta, resolución, calendarios y condiciones de pausa. |
| [Automatización de procesos](docs/automations.md) | Reglas de negocio, asignaciones y seguimiento de solicitudes. |
| [Matriz de prioridades](docs/priority-matrix.md) | Clasificación de incidentes según impacto, urgencia y criticidad. |
| [Arquitectura funcional](docs/architecture.md) | Diseño de componentes, integración funcional y procesos de atención del Service Desk. |


## 🔍 Metodología de implementación

El proyecto comprendió las siguientes etapas:

1. Análisis de requerimientos.
2. Diseño funcional de la solución.
3. Configuración de Jira Service Management.
4. Implementación de workflows y reglas de negocio.
5. Configuración de SLA y prioridades.
6. Validación mediante pruebas funcionales.
7. Documentación técnica y mejora continua.

## 📌 Estado del proyecto

Implementación y configuración realizadas, con pruebas funcionales y documentación de los procesos.

Algunas automatizaciones están sujetas a las capacidades del licenciamiento utilizado.
